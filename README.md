# 🏦 Bankruptcy Prevention AI

Professional machine learning application designed to predict business bankruptcy risk using a Random Forest Classifier.

## 🌟 Key Features
- **Real-time Assessment:** Instant risk scores based on 6 business dimensions.
- **Premium UI:** Polished interface with interactive sliders and metrics.
- **Explainable AI:** Uses models optimized for both accuracy and reliability.

## 📂 Project Structure
- `app.py`: Main Streamlit application.
- `bankruptcy_model.pkl`: Trained Random Forest model.
- `requirements.txt`: List of dependencies.
- `bankruptcy-prevention.xlsx`: Dataset used for training.

## 🛠️ Installation
If running locally:
```bash
pip install -r requirements.txt
streamlit run app.py
```
